Syntaxe DNA

Les atomes DNA sont les briques de base de tout pattern BANG!. Ils s'enchaînent directement, sans séparateur.

Exemples DNA

x---x---       → kick sur 1 et 3
x-x-x-x-       → hi-hat double-croche
?-?-?-?-       → pattern 50% aléatoire
x-░-x-░-      → ghost notes sur les temps faibles

Syntaxe Babka ⚗

Extension de DNA avec la mini-notation Strudel. Tout pattern DNA reste valide. Les opérateurs structurels s'ajoutent par-dessus.

OpérateurSyntaxeComportement
[ ] [a b c] Subdivision — n atomes partagent 1 step. Durées divisées équitablement.
< > <a b c> Alternance — sélectionne une alternative par cycle (séparées par espaces).
( ) x(n,k) Euclidien inline — distribue n triggers sur k steps (algorithme de Bresenham).
[ ] + ( ) [x(n,k)] Euclidien overlay — k steps euclidiens compressés dans 1 step.

Subdivision [a b c]

[x x]           → 2 hits dans 1 step (16e → 32e)
[x x x]         → triolet dans 1 step
x-[x x]-        → step 1: hit · step 2: silence · step 3: 2 hits · step 4: silence
[x x]-[x x x]-  → combinaison subdivisions
La durée totale du groupe reste 1 step, quelle que soit la profondeur d'imbrication.

Alternance <a b c>

<x- -x>         → cycle 0: x- | cycle 1: -x | cycle 2: x- ...
<x---x--- x-[x-]x-->   → alternance de patterns complexes
<x ↺ ?>         → alterne hit / ratchet / prob sur chaque cycle
Les alternatives sont séparées par des espaces au niveau 0. Les imbrications <> ou [] internes sont correctement gérées.

Euclidien inline x(n,k)

x(3,8)          → 3 hits sur 8 steps : x--x--x-
x(5,8)          → 5 hits sur 8 steps : x-xx-xx-
?(2,8)          → 2 hits probables sur 8 steps
↺(2,8)         → 2 ratchets sur 8 steps
Tout atome DNA supporte le suffixe euclidien. Les k steps sont générés à durée 1.0 (inline = séquence plate).

Euclidien overlay [x(n,k)]

[x(3,4)]        → 3 hits sur 4 steps, compressés dans 1 step
[x(3,8)]        → 3 hits sur 8 steps dans 1 step (durées = 0.125 chacune)
L'overlay [x(n,k)] diffère de l'inline x(n,k) : les k steps sont normalisés pour tenir dans 1 step de base.

Combinaisons

x-[x x]-?              → hit · silence · 2 hits subdivisés · prob
<x---x--- x-[x-]x-->  → alternance de patterns avec subdivision
<[x x]- x-->           → subdivision dans une alternance
↺-[x ?]-░(2,4)        → ratchet · silence · prob/hit subdiivisés · 2 ghosts sur 4

BangEngine API

from bang_engine import BangEngine, dark_chain
import babka

e = BangEngine(bpm=120, ticks_per_step=120,
               vel_floor=20, vel_ceiling=110, vel_curve=0.7)

e.add_voice(36, "x---x---")              # voix DNA simple
e.add_voice(42, ["x-x-", "x--x"])       # polyrythmie (liste de patterns)
e.add_markov_voice(dark_chain(), "x-?-") # mélodie Markov
e.add_babka_voice(38, "x(3,8)")         # voix Babka euclidienne
e.add_babka_voice(36, "<x-[x x]- [x x]-->")  # alternance + subdivision
e.add_cc_drone(control=74, breakpoints=[20, 100, 20])

e.export_midi(num_steps=64, filename="out.mid")
