Concept

BANG! EST

  • Un générateur de patterns MIDI algorithmiques
  • Des modes correspondant à des usages prédéfinis (batterie, basse, synths)
  • Des presets câblés au matériel (Volca Drum, Volca Kick, Volca FM, MicroFreak…)
  • Un player intégré — Web MIDI ou synthé navigateur (Web Audio), pianoroll synchronisé
  • Un synthé navigateur — preview audio sans matériel MIDI, tous navigateurs
  • Des clips Ableton par voix — bouton ↓ drag-and-drop vers la session view
  • De la polymétrie par voix — cycles indépendants configurables via bouton Ns
  • Du MIDI Learn — capture de pattern depuis un clavier physique (Chrome)
  • Des P-locks CC par step pour les synths hardware
  • Des gammes configurables pour les modes mélodiques — 12 toniques × 8 modes

BANG! N'EST PAS

  • Un séquenceur temps réel — les patterns ne tournent pas dans BANG
  • Un DAW — pas de clips, pas de timeline, pas de routing audio
  • Un plugin — c'est une app web locale servie en réseau
  • Un outil de mixage ou d'arrangement

Le workflow est simple : Générer → Écouter → Ajuster → Exporter. Le rendu final se fait dans le DAW. BANG s'occupe uniquement de produire des .mid intéressants.

BANG repose sur une logique de complexité sous-marine : structures simples en surface, mécanismes chaotiques en profondeur. Entropie multi-sources (os.urandom + horloge ns + fragment clé SSH + météo), polyrythmie native (chaque voix a sa propre longueur de cycle), mutations DNA probabilistes.

Ce que BANG génère — les fichiers .mid

Chaque export produit un fichier .mid standard, lisible par tout DAW. La structure interne varie selon le mode.

Batterie standard — modes Morph, Random, Weather, Noise, Ambient, Babka

Plusieurs pistes MIDI sur canal 10 (GM drums). Chaque voix correspond à une note (Kick 36, Snare 38, HH 42…). Les patterns ont des longueurs indépendantes — le cycle global ne se répète jamais à l'identique.

Canal 10 · note 36 (Kick)  · pattern 16 steps
Canal 10 · note 38 (Snare) · pattern 8 steps
Canal 10 · note 42 (HH)    · pattern 16 steps
Canal 10 · note 24 (Bass)  · pattern 5 steps   ← décalage polyrythmique

Ligne de basse — mode Bassline ♩

2 voix mélodiques sur canal 1 pilotées par une chaîne de Markov. La tonique et la gamme sont configurables (ROOT + SCALE) — défaut A pentatonique mineur, 2 octaves. Les notes changent à chaque step selon une matrice de transitions pondérées par distance de degré et gravité tonique/quinte. Un drone CC74 (filtre) et optionnellement CC5 (portamento) sont exportés sur la même piste.

Canal 1 · notes Markov [ROOT] [SCALE] 2 octaves · 2 patterns indépendants
Canal 1 · CC74 (filtre) drone continu
Canal 1 · CC5  (portamento) si chaos > 0.35

Markov mélodique — modes Markov, Phase 2

Batterie standard + 1 voix mélodique Markov. Tonique et gamme configurables (ROOT + SCALE) — défaut A pentatonique mineur, 1 octave. Phase 2 ajoute un kick polyrhythmique (2 patterns morphés) et un second drone CC91 modulé par la météo.

Korg Volca Kick ★ — mode Volca Kick

1 voix sur canal 1. La note MIDI (défaut C3/60) contrôle la hauteur de l'oscillateur du Volca Kick. 5 P-locks CC automatisés par step :

CCParamètreStyle

Korg Volca FM ⚡ — mode Volca FM

3 voix polyphoniques sur canal 1. Notes : FM1=C1 (36), FM2=G1 (43), FM3=C2 (48). P-locks sur FM1 seulement (les paramètres FM sont globaux au patch) :

Korg Volca Drum ★ — mode Volca Drum

6 voix sur 6 canaux MIDI distincts (ch1→ch6, Split Channel mode du Volca Drum). Note envoyée : C3 (60) — seul le canal identifie la part. Max 16 steps (limitation du séquenceur interne). P-locks sur chaque part :

Arturia MicroFreak ◈ — mode MicroFreak

3 voix paraphoniques sur canal 1. Notes : MF1=A2 (45, lead), MF2=E2 (40, contre), MF3=C2 (36, pédale). P-locks sur MF1 :

CCParamètreStyle
13Cutoffsweep — ouverture/fermeture filtre

12Shapetexture — morphing forme d'onde
16LFO Amountspikes — accents expressifs
15LFO Ratesweep — vitesse vibrato variable
Les P-locks sont exportés dans le .mid comme des événements CC normaux, lisibles dans n'importe quel DAW. Dans Ableton, ils apparaissent dans l'automation des tracks MIDI. La lecture dans un DAW avec le matériel branché en MIDI Out envoie l'automation directement au synth.

Thinning de voix (÷2 / ÷4)

Réduit la densité d'une voix sans modifier le pattern DNA. ÷2 garde 1 trigger sur 2, ÷4 garde 1 sur 4. Appliqué aussi bien au pianoroll qu'à l'export MIDI.

Contrôles par voix

Chaque voix dispose de contrôles individuels dans le panneau central, indépendants de la génération globale.

Lock 🔒

Verrouille une voix : elle ne sera pas régénérée lors des prochains clics sur Generate. Indiqué par une bordure colorée sur la ligne. Le ring buffer Undo préserve l'état des locks.

Workflow : fixer le groove kick+snare → 🔒 les deux voix
           → générer pour varier le hihat et les éléments secondaires

Densité (0–1)

Multiplie la probabilité de déclenchement de chaque step. Appliqué à l'export MIDI et au player. 1.0 = normal · 0.5 = moitié des triggers supprimés · 0.0 = silence.

Polymétrie — bouton Ns

Définit un cycle indépendant de N steps pour cette voix. Cliquer le bouton ouvre un champ numérique : entrer N + Entrée. Entrer 0 pour reset. Voir section Polymétrie pour le détail.

MIDI Learn — bouton ⏺

Lance la capture de pattern depuis MIDI entrant. Chrome/Chromium uniquement. Voir section MIDI Learn.

Clips Ableton — bouton ↓

Télécharge le clip MIDI de cette voix uniquement. Draggable (Chrome). Voir section Clips Ableton.

Euclidien — bouton E

Remplace le DNA d'une voix par un rythme euclidien E(n, k) où n = longueur du pattern courant et k = nombre de hits à saisir. Algorithme Bresenham — distribue k hits aussi uniformément que possible sur n steps.

E(n, k)Pattern (n=16)Contexte musical
k=2x-------x-------Kick minimaliste
k=3x-----x----x----Kick asymétrique
k=4x---x---x---x---Four on the floor
k=5x---x--x--x--x--Clave afro-cubaine approx.
k=7x--x-x-x--x-x-x-Bol / pattern turc
k=8x-x-x-x-x-x-x-x-Hi-hat double croche
k=3 / n=8x--x--x-Afro-cubain classique 3/8
Cliquer E sur une voix → saisir k → Entrée. Le pattern remplace le DNA existant, le pianoroll se met à jour immédiatement.

Polymétrie par voix

Chaque voix peut tourner sur un cycle indépendant, différent du nombre de steps global. La collision de cycles de longueurs différentes crée naturellement de la polymétrie — les patterns ne se répètent qu'au LCM des longueurs.

Utilisation

Chaque voix (hors CC et Babka) dispose d'un bouton Ns dans le panneau DNA, où N est la longueur courante. Cliquer ouvre un champ numérique :

  • Entrer un nombre entre 1 et 256 puis Entrée → le cycle de cette voix est fixé à N steps
  • Entrer 0 puis Entrée → reset, la voix reprend la longueur globale

Comportement du DNA

Quand N est différent de la longueur du DNA courant :

  • N < DNA → troncature : les steps excédentaires sont supprimés
  • N > DNA → répétition + troncature : le DNA est dupliqué jusqu'à atteindre N
# DNA source : "x---x---" (8 steps)
# N=5  → "x---x"                    (troncature)
# N=12 → "x---x---x---"             (répétition)

Persistance

Le cycle indépendant survit aux ∿ Varier et à l'Undo. Un Generate sur une voix non verrouillée remet la longueur par défaut — verrouiller la voix avec 🔒 avant de générer pour préserver son cycle.

MIDI Learn — capture de pattern

Capture un pattern rythmique directement depuis un clavier MIDI physique ou un pad controller. Les hits sont quantifiés sur la grille du pattern courant.

MIDI Learn requiert Chrome ou Chromium (Web MIDI API). Firefox et Safari ne supportent pas cette fonctionnalité.

Configuration préalable

  1. Cliquer 🎹 MIDI dans le toolbar → modal MIDI
  2. Sélectionner le port MIDI entrant (port IN) dans la liste
  3. Fermer le modal

Capture

  1. Cliquer ⏺ sur la voix cible → l'interface passe en mode armé (⏺ rouge clignotant)
  2. Jouer un premier hit sur le clavier MIDI → le count-in démarre (2 steps basés sur le BPM courant)
  3. Jouer le pattern pendant 1 cycle complet — les hits sont capturés en temps réel
  4. Au bout d'un cycle (steps × step_ms ms), la capture s'arrête automatiquement
  5. Le DNA de la voix est remplacé par le pattern capturé et quantifié

Quantification

Chaque hit MIDI reçu est assigné au step le plus proche dans la grille (arrondi au step entier). Si deux hits tombent sur le même step, seul le premier est retenu.

# BPM 120 · 16 steps → step_ms = 125 ms
# Hit reçu à t=0ms    → step 0 (x)
# Hit reçu à t=258ms  → step 2 (x)    (2 × 125ms = 250ms, delta 8ms)
# Hit reçu à t=1000ms → step 8 (x)    (8 × 125ms)

Annulation

Cliquer à nouveau sur ⏺ pendant l'armement annule la capture sans modifier le DNA.

Clips Ableton Live

BANG génère des clips MIDI individuels par voix, exportables et glissables directement dans Ableton Live.

Bouton ↓ par voix

Dans le panneau DNA, chaque voix non-CC expose un bouton ↓ :

  • Clic → télécharge le clip MIDI de cette voix uniquement (nom.mid)
  • Drag (Chrome) → glisser vers la Session View ou l'Arrangement View d'Ableton insère le clip directement
Drag → Ableton fonctionne uniquement sur Chrome/Chromium via l'API DownloadURL. Sur Firefox, utiliser le clic pour télécharger puis importer manuellement.

Label pianoroll cliquable

Les labels de voix dans le pianoroll SVG (à gauche) sont des liens cliquables : cliquer télécharge le clip de la voix correspondante.

Tous les clips

Le bouton ↓ Tous les clips en bas du panneau DNA génère un fichier zip contenant un clip MIDI séparé pour chaque voix non-CC. Nom du fichier : bang-clips-YYYYMMDD-HHMMSS.zip.

Endpoints

MéthodeRouteDescription
GET/export/clip?idx=NClip MIDI mono-voix (voix à l'index N). Swing, microtiming, densité et accords appliqués.
GET/export/clipsZip de tous les clips individuels. Nom : bang-clips-timestamp.zip.

Workflow Ableton

1. Générer un pattern dans BANG
2. Sélectionner un preset (preset Tekno, GM…)
3. Glisser le clip ↓ "Kick" vers une piste MIDI Ableton mappée sur le kick
4. Glisser ↓ "Snare" sur une autre piste
5. Jouer les clips en boucle dans la Session View
6. Cliquer ∿ Varier dans BANG → télécharger les nouvelles variations → remplacer les clips

Gammes configurables

Les modes markov, phase2 et bassline utilisent une chaîne de Markov construite algorithmiquement à partir d'une tonique (ROOT) et d'un mode scalaire (SCALE). Les sélecteurs apparaissent dans l'interface uniquement pour ces trois modes.

La matrice de transitions est pondérée par : distance de degré (préférence stepwise), gravité tonique (×1.5) et quinte (×1.2), pénalité de répétition (×0.35). Markov utilise 1 octave, Bassline 2 octaves.

dorian0 2 3 5 7 9 10Dorien — jazz, funk, modal
phrygian0 1 3 5 7 8 10Phrygien — espagnol, flamenco, metal
major0 2 4 5 7 9 11Majeur — classique, pop
mixo0 2 4 5 7 9 10Mixolydien — rock, dominante

Patterns mélodiques (voix Markov — DNA détermine les silences)

x---x---x---x---    → mélodie pulsée, 4 notes
x-?-x-?-x-?-x-?-   → demi probabiliste — respiration
x-------x-------    → longues notes (tenues en MIDI)
?-?--?--?-?--?--    → sparse, flottant
↺---x-?-↺---x---   → ratchets expressifs
x-x-?---x-x-?---    → motif répété avec variation

Babka — subdivision

Les crochets [ ] subdivisent un step en n parties égales.

[x x]-x-[x x]-x-    → kick en 32e sur les 1er et 3ème beats
[x x x]-------------→ triolet sur le 1er step seulement
x-[x x]-x-[x x]-    → double sur les temps faibles
[x -]-x-[x x]-x-    → avec silences dans subdivision
[x x x x]---x---    → quadruplet + kick simple

Babka — alternance

Les chevrons < > tournent entre alternatives à chaque cycle.

<x-x- ?-?->              → alterne un pattern dense et un sparse
<x---x--- x-x-x-x->      → alterne groove lent et rapide
<x--x-x-- x---x--->      → alterne clave et kick simple
<x--- ---->               → son présent 1 cycle sur 2
<x-x- x-- x-x-x->        → rotation 3 variantes

Babka — euclidien inline

La notation x(k,n) distribue k hits sur n steps dans un seul token.

x(3,8)               → x--x--x-  (3/8, afro-cubain classique)
x(5,8)               → x-xx-xx-  (5/8, quintolet)
x(5,16)              → x---x--x--x--x-- (clave)
x(7,16)              → x--x-x-x--x-x-x- (bol turc)
↺(2,8)              → 2 ratchets euclidiens sur 8 steps
?(3,8)               → 3 hits probabilistes euclidiens
[x(2,3)]--x--        → euclidien compressé dans 1 step

Babka — combinaisons

OSC Bidirectionnel

BANG envoie et reçoit des messages OSC en UDP. Activer via OSC ○ dans le toolbar → modal config → Start. Les deux serveurs (TX et RX) démarrent simultanément.

Messages sortants (↑ TX)

MessageArgumentsDescription
/bang/clock[step, total_steps]Émis à chaque step du pattern
/bang/{NomVoix}[step, velocity, note]Par trigger, par voix qui sonne ce step

NomVoix = label de la voix (Kick, Snare, HH, Markov, KSP Lead…). Défaut TX : 127.0.0.1:57120.

Messages entrants (↓ RX)

BANG écoute sur 0.0.0.0:57121 (configurable). Envoyez ces messages depuis SC, Max, TouchDesigner, Python…

MessageArgumentsEffet
/bang/param/bpmint (40–240)Change le BPM immédiatement
/bang/param/chaosfloat (0–1)Change le chaos (utilisé à la prochaine génération)
/bang/param/gravityfloat (0–1)Change la gravité Markov
/bang/param/swingfloat (0–1)Change le swing
/bang/param/microtimingfloat (0–1)Change le micro-timing

/bang/param/cc_depthfloat (0–1)Change la profondeur CC (p-locks)
/bang/generate—Regénère le pattern complet (params courants, locks respectés)

SuperCollider — Recevoir depuis BANG (TX)

// Écouter le clock global
OSCdef(\bangClock, { |msg|
    var step = msg[1], total = msg[2];
    if (step == 0) { "--- new cycle ---".postln };
    step.postln;
}, '/bang/clock');

// Déclencher un synthé sur le Kick
OSCdef(\bangKick, { |msg|
    var step = msg[1], vel = msg[2], note = msg[3];
    Synth(\bd, [\amp, vel / 127, \freq, note.midicps]);
}, '/bang/Kick');

// Mélodie Markov → synthé mélodique
OSCdef(\bangMarkov, { |msg|
    var vel = msg[2], note = msg[3];
    Synth(\blip, [\freq, note.midicps, \amp, vel / 127]);
}, '/bang/Markov');

from bang_engine import BangEngine, build_markov_chain, SCALE_INTERVALS

e = BangEngine(bpm=120, vel_floor=20, vel_ceiling=110, vel_curve=0.7)

e.add_voice(36, "x---x---")                        # DNA simple, ch10
e.add_voice(42, ["x-x-", "x--x"])                  # polyrythmie (liste)
e.add_voice(60, "x---x-?-x---x---", channel=0)     # Volca Kick, ch1

# Mélodie Markov — D dorien, 1 octave
chain = build_markov_chain(root_note=50, intervals=SCALE_INTERVALS["dorian"], num_octaves=1)
e.add_markov_voice(chain, "x-?-")

# Basse Markov — C pentatonique mineur, 2 octaves
bass = build_markov_chain(root_note=36, intervals=SCALE_INTERVALS["penta_min"], num_octaves=2)
e.add_markov_voice(bass, "x---x-x-")

e.add_babka_voice(38, "x(3,8)")                     # euclidien

Résolution de problèmes

Le player ne démarre pas

  • Sans port MIDI sélectionné : le player utilise automatiquement le synthé navigateur. Cliquer ▶ Play directement.
  • Autoplay bloqué : si aucun son au premier clic, cliquer une fois n'importe où sur la page (geste utilisateur requis par les navigateurs) puis relancer.
  • Firefox / Safari : Web MIDI non supporté → le synthé navigateur prend le relais automatiquement. Le player fonctionne, MIDI Learn et drag Ableton sont indisponibles.

Web MIDI non disponible

  • Vérifier que le navigateur est Chrome ou Chromium.
  • Sur HTTPS, Web MIDI peut demander une permission explicite — accepter la popup.
  • Connecter le périphérique MIDI avant d'ouvrir le navigateur.

MIDI Learn ne capte rien

  • Ouvrir le modal 🎹 MIDI → vérifier qu'un port MIDI entrant (IN) est sélectionné.
  • Jouer un hit MIDI pour déclencher le count-in — le bouton ⏺ doit clignoter en rouge en mode armé.
  • Chrome uniquement — Firefox et Safari ne supportent pas Web MIDI.

Drag → Ableton ne fonctionne pas

  • Chrome/Chromium uniquement (API DownloadURL). Sur Firefox, clic pour télécharger puis import manuel.
  • Ableton doit être visible à l'écran — glisser vers une piste MIDI existante ou une cellule vide de la Session View.
  • Sur macOS, le drag-and-drop inter-application peut nécessiter d'autoriser l'accès dans les préférences de sécurité.

OSC ne fonctionne pas

  • Vérifier que le port UDP 57120 (TX) et 57121 (RX) ne sont pas bloqués par le firewall : sudo ufw allow 57121/udp.
  • Le serveur RX redémarre à chaud quand le port change dans le modal OSC — inutile de relancer BANG.
  • Les voix Babka ne sont pas incluses dans l'OSC TX (timing fractionnel incompatible).

Erreur à l'install — uv sync échoue

# python-osc peut nécessiter des outils de build
sudo apt install python3-dev build-essential
uv sync

Port 7777 déjà utilisé

BANG_PORT=8888 uv run python web.py
# Ou identifier le processus
sudo lsof -i :7777

Export MIDI vide

  • Cliquer Générer avant Export — BANG ne génère pas au démarrage.
  • Si le mode weather est utilisé sans connexion internet, BANG utilise des valeurs par défaut — cliquer W pour forcer le refresh.
